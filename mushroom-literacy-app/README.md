# 蘑菇识字 · 儿童自然观察 App

亲子向的网页应用：拍照 / 上传蘑菇照片 → 趣味「颜色像谁」匹配 → 大字识字与朗读。

## 家规

**只看不吃。** 本应用不做食用鉴定，识别结果仅供识字与观察练习。

## 功能

- 相机拍照 / 相册上传
- 本地颜色相似度匹配（不依赖网络 API）
- 蘑菇图鉴 + 汉字卡片 + 听读音（浏览器语音）
- 认字小测验

## 本地运行

```bash
cd mushroom-literacy-app
npm install
npm run dev
```

构建：

```bash
npm run build
npm run preview
```

## 说明

若你有自己拍的蘑菇照片，可直接在「拍照」页上传；也可把照片放进 `public/samples/` 作为示例素材。
